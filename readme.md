# GPT-5 Telegram Bot 🤖

Телеграм-бот для доступа к GPT-5 через OpenAI API с монетизацией через Telegram Stars.

## 🚀 Попробовать бота

**Ссылка на бота:** [@ChatGPTTlgrmBot](https://t.me/ChatGPTTlgrmBot)

## 💡 Идея проекта

Предоставить минимальный доступ к GPT-5 за символическую плату. **1 Telegram Star = 1 запрос** — это намного выгоднее, чем подписка на ChatGPT за $20/месяц!

## ✨ Преимущества

- 💰 **Выгодная цена**: 1⭐ за запрос вместо $20/месяц за подписку
- 🎁 **Бесплатный старт**: Первый запрос бесплатно
- 💳 **Гибкая оплата**: Платите только за то, что используете
- 🔢 **Произвольные суммы**: Покупайте от 1 до 100 запросов за раз
- ⚡ **Быстрый доступ**: Без регистрации, прямо в Telegram
- 🆕 **Новейшая модель**: Доступ к GPT-5
- 📊 **Прозрачность**: Видите остаток запросов после каждого использования
- 🔓 **Open Source**: Исходный код доступен для всех

## 🎯 Особенности

- **Команда /start**: Приветствие пользователей с бесплатным запросам
- **Команда /help**: Подробная инструкция по использованию
- **Команда /balance**: Проверка баланса запросов
- **Команда /buy**: Покупка запросов через Telegram Stars
- **Команда /dev**: Информация о разработчике и проекте
- **Команда /stat**: Статистика для администраторов (пользователи, запросы, выручка)
- **Произвольные суммы**: Возможность указать любое количество запросов (1-100)
- **Обработка сообщений**: Генерация ответов с использованием GPT-5
- **Индикатор "печатает..."**: Визуальная обратная связь во время обработки
- **Валидация**: Проверка длины сообщения (10-4000 символов)
- **SQLite база данных**: Хранение пользователей, запросов и платежей
- **Telegram Stars**: Встроенная система оплаты

## 📦 Установка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/king-tri-ton/chatgpt-telegram-bot.git
   cd chatgpt-telegram-bot
   ```

2. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

3. **Создайте файл .env**
   
   Скопируйте `.env.example` и переименуйте в `.env`:
   ```bash
   cp .env.example .env
   ```

4. **Заполните переменные окружения в .env**
   ```env
   AI_TOKEN=your_openai_api_token
   BOT_TOKEN=your_telegram_bot_token
   ADMIN_ID=your_telegram_user_id
   DB_NAME=your_db_name
   ```
   
   - **AI_TOKEN**: Получите на [platform.openai.com](https://platform.openai.com/api-keys)
   - **BOT_TOKEN**: Получите у [@BotFather](https://t.me/botfather) в Telegram
   - **ADMIN_ID**: Ваш Telegram ID (узнать можно у [@username_to_id_bot](https://t.me/username_to_id_bot))
   - **DB_NAME**: Название базы данных SQLite3

## 📖 Использование

1. Найдите бота в Telegram: [@ChatGPTTlgrmBot](https://t.me/ChatGPTTlgrmBot)
2. Отправьте `/start` для начала работы (получите 1 бесплатный запрос)
3. Отправляйте сообщения (10-4000 символов) для получения ответов от GPT-5
4. Используйте `/balance` для проверки остатка запросов
5. Используйте `/buy` для покупки дополнительных запросов через Telegram Stars
6. Администратор может использовать `/stat` для просмотра статистики

## 💳 Система оплаты

Бот использует **Telegram Stars** для монетизации:

- 🎁 **1 бесплатный запрос** при регистрации
- ⭐ **1 Telegram Star = 1 запрос** к GPT-5
- 💰 Быстрые варианты: 1, 5, 10, 25, 50, 100 Stars
- ✏️ Произвольная сумма: от 1 до 100 запросов
- 📊 История платежей сохраняется в базе данных

## 🛠 Требования

- Python 3.7+
- Telegram аккаунт
- OpenAI API ключ с доступом к GPT-5
- Библиотеки из requirements.txt:
  - pyTelegramBotAPI (telebot)
  - openai
  - python-dotenv
  - sqlite3 (встроен в Python)

## 📊 База данных

Бот использует SQLite3 с тремя таблицами:

- **users**: Информация о пользователях и их балансе запросов
- **results**: История запросов и ответов с метриками токенов
- **payments**: История платежей через Telegram Stars
